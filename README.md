# IndigoLearn ACCA Landing Page

A responsive ACCA (Association of Chartered Certified Accountants) landing page built with React.js and Tailwind CSS. The project is designed to provide a clean, responsive user experience for students interested in ACCA courses and preparation.

## 🚀 Live Demo

[View Live Website](https://indigo-learn-acca-react-git-main-sameers-projects-634e68e6.vercel.app/)

## 📌 Project Overview

The IndigoLearn ACCA Landing Page is a frontend project that presents ACCA course information, learning benefits, eligibility details, placement assistance, and a callback enquiry form.

The project focuses on:

* Responsive design for desktop and mobile devices
* Reusable React components
* React state management for interactive UI
* Mobile navigation menu
* Callback enquiry form
* Success modal after form submission
* Smooth navigation between sections

## ✨ Features

### Responsive Header

* IndigoLearn branding

* Mobile navigation menu
* Responsive layout using Tailwind CSS

### Hero Section

* ACCA course introduction

### Why Choose Us

Highlights:

### ACCA Eligibility

Provides information about:

### What Will You Learn

Displays the ACCA learning structure:

* Knowledge Level

* Professional Level

### Placement Assistance

Includes information about:

* Resume Building
* Career Counselling
* Job opportunities

### Callback Modal

When the user submits the callback form, a success modal is displayed. The modal can be closed using the Close button.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/SameerMNC/indigo-learn-acca-react.git
```

Navigate to the project:

```bash
cd indigo-learn-acca-react
```

Install dependencies:

```bash
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### Production Build

To create a production build:

```bash
npm run build
```

## 🔄 Deployment

The project is deployed using Vercel.

The project is connected to the GitHub repository, so new changes pushed to the `main` branch can trigger a new Vercel deployment automatically.
